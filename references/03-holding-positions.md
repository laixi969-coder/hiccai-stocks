# 03 · 持有期与加减仓

持有期是买入理由的验证窗口，不是保证获利的等待期。期限、仓位和复查规则统一见 [06](06-annual-cycle-template.md)。

## 先确定策略

| 策略 | 原手册参考窗口 | 复查与退出条件 |
|---|---|---|
| 估值修复 | 3–12 个月 | 事前定义估值兑现区间、价值陷阱信号及到期重评日期 |
| 产业趋势 | 1–3 年 | 按季度验证订单与盈利；普通波动可观察连续两季，重大证伪不能机械等两季 |
| 半年事件/估值交易 | 约半年，仅主动要求时展开 | 明确催化剂及日期、价格与逻辑止损、交易可执行性，仓位不超过同风险预算长期仓的一半 |
| 未有可证伪理由 | 未定 | 暂不形成新增计划，先补理由 |

时间长短不能严格区分“赚企业的钱”与“赚别人的钱”；任何窗口都可能同时受盈利预期、估值、利率及资金影响。长期持有也有重评时点，不能无期限续期。

原手册短线 −8% 至 −10% 止损是示例参数，仅在用户选择该交易策略、能跟踪且事前设定时使用。跳空、跌停和流动性不足可能使实际损失超过止损线，不能把计划止损当最大损失保证。低频投资者默认不扩展到 2–3 个月波段。

## 白名单及其前提

执行顺序：**支出与流动性约束 → 杠杆及集中度限制 → 重大证伪 → 既定策略条件 → 日常白名单**。资金用途改变或风险超限是合理重评原因，不算纪律失败。

| 方向 | 白名单 | 条件 |
|---|---|---|
| 加仓 | 固定定投日 | 资金分层仍成立、未超仓位上限、标的逻辑未证伪；行业新增还须过拥挤度闸门 |
| 加仓 | 再平衡补少 | 已达约定阈值，补入后仍满足风险约束；新增现金可优先用于补少 |
| 加仓 | 计划内补仓 | 价格/估值触发、每次金额、最大次数、累计上限已写好，并再次核对反证 |
| 减仓 | 卖出条件触发 | 按既定认错线或兑现线处理，注明当前证据 |
| 减仓 | 再平衡卖多 | 达到组合比例阈值，考虑交易成本 |
| 减仓 | 基本面证伪 | 出现足以推翻原理由的可靠信息，无须等价格止损或两季确认 |

定投、再平衡与拥挤度闸门冲突时，不强行加回行业仓；将待配置资金保留为投资现金，记录偏离原因与重评条件，不自动转投其他产品。宽基定投不因为单一行业的拥挤度直接停投，但需检查穿透集中度。

没有触发条件时维持原计划；信息不足时先核验，不能写成“已证实没风险”。事后补写计划需注明补写日期，不伪装成买入时已有的纪律。

## 买入条件与持有条件不对称

估值超过新增门槛、基金规模初筛不达标等，不自动成为现有持仓的卖出依据；检查它是否改变原持有理由、产品存续风险或已写下的退出条件。买入成本用于损益和成本记录，不能以“回本再卖”替代从当前价格评估。

反过来，也不能因盈利逻辑仍在就忽略已经约定的估值兑现、风险超限或支出变化。换仓要比较新旧标的的当前条件、增量风险与交易成本；新标的研究排名更高不足以支持换仓。

## 从条件触发到实际完成

计划记录触发依据、当前/目标金额、资金来源、执行窗口与到期复核。核对适用市场的最小交易单位、可卖数量、停牌/涨跌幅限制、赎回到账、价差、费用与适用税费；需要时查最新官方条款，不预置跨市场通用规则。

触发、拟执行、部分完成、实际完成分别记录。不把假设成交价当成交事实；卖出所得未到账不能自动作为可用现金。实际成交或新增现金改变金额后重新计算仓位。无法交易时记录未完成及剩余风险，不能声称止损或再平衡已生效。本 skill 生成计划，不操作账户。
