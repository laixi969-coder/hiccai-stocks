# 08 · 数据、来源与不确定性

## 核验顺序

优先使用对应市场的公司公告、交易所、监管机构、指数公司、基金管理人产品资料；行业数据使用政府、行业协会或企业原始披露。搜索摘要、券商二次解读和社交媒体可提供线索，关键结论尽量回到原文。公司预测也是预测，不能因出自官方就当实际兑现。

仅解释本手册方法不必抓行情。涉及实时估值、下跌原因、业绩、基金条款或实际买卖分析时必须核验。当前环境无联网能力时，可分析用户材料并标“用户提供，未独立核验”，不给最新性背书。

## 最小证据记录

| 项目 | 要记录的口径 |
|---|---|
| 标识 | 市场、公司/基金/指数名称及必要代码 |
| 数值 | 单位、币种、百分数与百分点；实际/预测/估算 |
| 日期 | 数据截至日、报告期、公布日；盘中/收盘及交易所时区 |
| 定义 | PE类型、复权、总回报/价格回报、历史分位窗口等 |
| 来源 | 可点击原文链接；资料不可访问或仅摘要须说明 |

行情使用最近可得交易时点；非交易日不标成当日收盘。财报用最新已公开报告期，同时注明披露日。分析历史决策，只用当时已公开的信息；事后信息单独作为复盘。

同名公司、不同上市地/份额必须确认标识，比较数据统一币种与时间点。年内累计数、单季度数和TTM不能混用；同比与环比、总股本与流通股本、现价与历史复权价分别标注。拆股、分红和其他公司行动先核对再解释跌幅，不能把除权价格变化全当投资亏损，也不能把复权价格当实际可成交价。

“最新可得”不等于“足够新”：记录每个关键字段的观察期，检查之后是否有新财报、客户变化、融资或产品条款改变。资料过旧但没有更新时标“当前适用性待核实”，不能补写今天的日期。保存资料定位（公告编号、页码/表名或原始字段）及取得日期；本地快照仅在来源许可和任务需要时保存，不大量复制无关全文。

## 分位与拥挤度

优先引用来源已解释的分位算法。自行计算时写明样本频率、窗口、缺失与并列值规则；一种可选算法为 `100 × (低于当前值的样本数 + 0.5 × 等于当前值的样本数) / 有效样本数`。不要与不同算法的来源直接拼接。

本手册拥挤度代理：行业成交额/同口径全市场成交额的历史分位。必须说明行业分类、日频或滚动均值、市场范围和历史区间；如自行选用5年日频历史，明确这是当前研究设定。指标与机构持仓、换手率分位不同，不能替代使用而不说明。没有可比序列时标未知。

## 证据不足与冲突

- 找不到某项数据：标未知，提供可验证路径与该缺口影响的结论。不虚构数字、来源、排名或精确止损价。
- 来源打架：先查日期、样本、复权与单位；无法消解时并列差异，降低结论强度。
- 新闻声称“A导致下跌”：区分已发生事件和因果推断，多因素并存时不强选唯一原因。
- 对每个关键判断至少考虑一个可能推翻它的证据；不要机械要求两个独立来源才能使用单份权威公告。

## 证据必须对应主张

来源权威性不等于对所有推论都有效。每项记录“主张→证据→能支持什么→不能支持什么→反证/未知”。同一公告被多家媒体转述仍算同一证据根源。

| 材料 | 可支持的有限结论 | 不能直接推出 |
|---|---|---|
| 专利、论文 | 申请/披露的技术路线，注意申请与授权区别 | 客户采用、量产良率、商业独占 |
| 环评、能评、项目审批 | 获批规模或建设计划 | 已建成、满产、产生收入 |
| 客户认证或送样 | 对应阶段的进展 | 批量采购、长期独供 |
| 订单、框架协议 | 已披露的数量、约束和条件 | 全额收入、利润或回款；须查撤单条件 |
| 财报与现金流 | 对应期间已披露的经营结果 | 未来继续增长、未披露业务的精确贡献 |

关键商业主张只有专利/审批等间接证据时，状态是“部分支持”或“未知”；不得用来源数量提升为“已商业兑现”。

研究历史样本时保留退市、失败、未兑现候选及当时资料，防止幸存者偏差和事后挑选。若没有可复现数据，经验参数保持“未验证”，不声称有统计优势。
