# 09 · 产业链研究：从需求到利润归属

用于主题扫描、早期供应商研究、候选比较或挑战单家公司。承接 [01](01-board-funnel.md) 的研究池，证据遵守 [08](08-evidence-protocol.md)。研究不要求用户先提供账户资料，也不自动产生配置资格。

## 研究路径

1. **界定范围**：市场、主题与验证窗口，复用用户信息；不擅自把“现在值得研究”解释成短期交易。
2. **找系统变化**：需求为什么增长，旧架构哪里受限，约束是功率、带宽、散热、良率、认证还是其他因素。先写可验证假设，不从热门代码倒推。
3. **拆环节**：终端需求 → 系统 → 模组/器件 → 工艺/设备/材料 → 基础设施；按主题裁剪，不能把所有产业硬套半导体结构。
4. **比较约束**：供应商数量、替代方案、认证时间、扩产成本与时间、价格/交期、客户预付款。分别核验，不能把“供应商少”直接等同不可替代。
5. **映射公司**：区分控制瓶颈、供应瓶颈、普通需求受益者、只有叙事；保留重要未上市企业，揭示上市公司并不一定掌握瓶颈。
6. **验证利润归属**：按下表追问商业兑现，再进入 [10](10-earnings-valuation.md)。
7. **形成优先级**：先排环节，再排公司；解释证据、关键缺口、反方路径和下一检查事件。可并列，不为凑名单强排。

## 瓶颈是否带来公司利润

| 问题 | 核验内容 |
|---|---|
| 谁真正需要它 | 终端需求、客户预算、在建项目与实际采购，排除重复计算上下游同一笔需求 |
| 客户是否绕得开 | 替代设计、二供、自产、降低规格或延迟建设 |
| 谁拿走收益 | 合同定价、成本传导、议价能力、单位毛利与客户集中度 |
| 公司拿到多少 | 相关业务收入占比、供应份额、交付能力，不把产业规模当公司收入 |
| 瓶颈持续多久 | 竞争对手扩产、技术替代、需求窗口与本公司量产时点 |
| 兑现前是否缺钱 | 现金、经营消耗、债务到期、资本开支、融资及潜在稀释 |

## 早期研究与风险调查

认证、试产、量产、收入、回款是不同阶段。尚未盈利的企业可以研究，但必须披露现金可支持的时间及融资不确定性；现金消耗季节性强时不能机械用一个季度外推。

严重且未解决的治理、偿债或退出流动性问题，阻断新增配置；可保留风险调查或持仓诊断。缺资料与已证实风险分开，不能为了通过检查把未知记为零。

不要求固定“20家公司、25个来源”。覆盖主要经济环节、替代者与关键反证；当新增检索没有解决关键缺口时，交付范围、已覆盖部分、待验证事项和停止原因。规模较大的候选池不扩大重点跟踪或持仓数量。

## 输出

使用“环节/公司、角色、证据状态、研究优先级、反方理由、下一验证”表或短段落。配置状态另报；缺账户信息时为未评估。没有证据支撑的名字只作为待验证线索，不包装成高确定性机会。
