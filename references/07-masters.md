# 07 · 思想溯源：规则背后的启发

本节是手册作者对投资思想的应用性映射，不是大师亲自制定数值门槛的证据。具体引语、人物方法与历史业绩应核验原始出处，不用名人权威证明规则有效。

## 八位投资者与手册规则

| 人物 | 思想主题 | 手册中的应用 |
|---|---|---|
| 格雷厄姆 | 安全边际、市场先生 | 区分价格与价值，估值筛选只是进一步研究的入口 |
| 巴菲特 | 能力圈、护城河 | 控制跟踪范围，检查竞争优势是否持续 |
| 芒格 | 逆向思考 | 买入前先写失败情景与认错条件 |
| 费雪 | 产业链调查 | 用客户、供应链与公开原始资料交叉验证，区别线索与证据 |
| 林奇 | 按公司类型分析 | 匹配估值方法与验证周期，不把成长股门槛用于所有行业 |
| 霍华德·马克斯 | 周期、风险、价格与价值的关系 | 将估值、拥挤度与损失承受范围一起看 |
| 段永平 | 不懂不做、企业视角 | 先理解商业与买入理由，再决定是否进入观察池 |
| 冯柳 | 弱者体系 | 承认信息和研究局限，重视价格、仓位与纪律 |

原手册把整套方法称为散户版“弱者体系”，保留为作者的定位。它并不完整复刻任何人的策略，也不能把这些投资者简单分成“只研究”或“只看位置”两类。

## 阅读路径

- 想理解价格波动与安全边际：从《聪明的投资者》第8、20章入手；周期与风险可读《投资最重要的事》相关章节。
- 开始年度复盘后：结合巴菲特股东信与有可靠出处的段永平问答，回看自己是否按企业价值作判断。
- 确定要研究个股后：再读费雪《怎样选择成长股》与林奇《彼得·林奇的成功投资》，将阅读转成可验证的研究问题。

这是原手册的学习路径，不要求先读完才能制定资金与风险规则。用户询问版本、最新资料或人物具体说法时，再查出版信息或原文。

## 遇到新打法或“股神”案例

先核验业绩区间、基准、费用、最大回撤、是否审计，以及公开推荐与实际持仓时间。再比较资金期限、杠杆、流动性、盯盘与研究需求。无法验证就说明无法验证；可借鉴思路，不直接复制标的和仓位。跟单风险细节见 [05](05-drawdown-anatomy.md)。
