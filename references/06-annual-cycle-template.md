# 06 · 资金分层、统一参数与年度循环

这是跨模块策略参数与仓位口径的唯一维护位置；产品专用筛选门槛在 [02](02-target-selection.md) 维护。原手册参数保留为策略默认值；用户已定规则需注明来源和日期，若与资金用途或损失承受范围冲突，应指出冲突并重评。

## 资金分层

- **活钱层**：未来 12 个月必要生活支出 + 不重复计入的大额支出 + 应急缓冲。原手册的 2–3 个月缓冲仅为起点，需考虑收入稳定性、负债与家庭责任。
- **中期资金**：预计 1–3 年取用或用途不确定，按实际使用日期和可承受本金损失安排；不能把“固收+”、二级债基、红利低波一并当现金替代品。
- **长期投资资金**：至少 3 年不需要动用是原手册筛查起点，并不意味着满三年就适合高权益比例或必然回本。继续检查目标、收入、负债与损失金额。

有固定近期开支的钱，先匹配可用日期和本金需求，再研究产品。货币基金、同业存单基金和短债基金不能一概描述为保本；具体净值风险与赎回到账须看当地产品文件。年底可能取用时，不机械给 25–30% 权益；也不因“继续滚存”自动配置 60–80% 权益。

## 仓位口径与默认参数

先定义：`A = 纳入本计划的金融资产总额`；`L = 活钱层`；`M = 已预留的中期资金`；`P = max(A − L − M, 0)`，为长期投资组合金额，包含其待投资现金。负债和还款安排单列，不把融资额度计入 P。若 P=0，不生成长期权益配置。

除另有说明，以下仓位都以 **P 为分母**；权益占全部金融资产的比例另报，不能混称“总仓位”。

| 参数 | 默认值与适用边界 |
|---|---|
| 核心/卫星 | 宽基作为核心，默认占权益部分≥50%；权益总额本身另由风险预算确定 |
| 卫星试仓/常规/较高仓位 | 5% / 10–15% / 最高20%，均为上限参考，不按主观信心自动放大 |
| 单一股票或单只行业/主题基金 | ≤P 的20%；多只同指数/高度重叠产品合并检查，不能拆产品规避 |
| 宽基核心 | 不机械套用单只卫星20%上限，仍检查底层行业与前十大持仓暴露 |
| 单行业穿透敞口 | ≤P 的30%，合并直接个股、行业基金和宽基中的行业权重；信息不足标未知 |
| 再平衡 | 实际资产类别权重与目标差的绝对值≥5个百分点；如30%→35%，不是30%×1.05 |
| 估值闸门 | 同口径近5年分位≤50%优先，50–70%观察，>70%默认不新增；>90%高估值观察 |
| 拥挤度闸门 | ≥90%暂缓新增行业仓，不是独立卖出条件 |

行业敞口 = Σ（持仓市值 × 该产品对应行业权重）÷ P。直接股票按其选定分类计入；使用同一行业分类，披露基金持仓数据的滞后性。新钱只有确定属于长期投资资金才增加 P，不能把活钱转入来“稀释”超限。

压力损失 = Σ（各资产金额 × 对应假设跌幅）。若只估计权益，`权益金额 × 50%` 是一个粗略情景，不代表其他资产无风险。最终允许仓位需同时满足资金期限、损失预算、产品与行业上限；取最严格约束，不平均折中。

## 买入前四行模板

| 字段 | 要填写的内容 |
|---|---|
| ① 理由 | “我认为 X 会在 Y 内发生，因为 Z”；Z 的来源/日期、关键反证与验证指标 |
| ② 退出/调整条件 | 认错线 + 兑现或再平衡线；说明价格、估值或基本面触发及执行方式。长期宽基可用目标调整/再平衡条件，不强设个股式目标价 |
| ③ 仓位 | P 的金额、当前和新增金额、交易后权重、行业穿透敞口；补仓触发、次数和累计上限；压力损失金额 |
| ④ 时限 | 建立计划日期、预期验证窗口、具体复查日期/事件；到期未兑现重新查证，记录继续或退出的依据 |

协助用户填写可知部分，不编造其资金、意愿或认错价。缺关键资料标“待核实”。事后补写标日期；不能为了避免认错悄悄改理由。修改计划时记录旧条件、新证据与调整理由。

## 年度循环

1. **年初定盘**：分层、目标配置、压力测试、再平衡与四行计划。
2. **年内守纪**：按 [03](03-holding-positions.md) 执行，月度查偏离，重大事件触发重评。
3. **季度归因**：核对账户收益、基准、风格暴露及主动偏离。
4. **年底留改扔**：保留有效流程、调整有证据的参数、删除无依据的假设，滚动制定下一年计划。

年度是决策节拍，不是强制清仓日。清仓本身不必然“使复利断裂”，应分析交易成本、税费、离场时间和资金目标。

## 季度归因四问的计算边界

- **赚亏多少**：金额损益 = 期末净资产 − 期初净资产 − 外部净流入；分红取现计外流，账户内交易不算外部流入流出。分红、手续费与税费不可重复计入。
- **市场给多少**：比较同币种、同区间、同分红口径基准。期内有存取款时，有完整估值用时间加权收益比较策略；现金流日期完整时可另算资金加权收益看个人体验。数据不够不要用“盈亏÷期初资产”冒充可比收益。
- **风格给多少**：用事前选择、权重合计100%的匹配基准组合比较。策略基准与宽基之间的差异仅是风格/配置代理，不是严格因果归因。
- **自己给多少**：相对匹配基准的差额还包含费用、现金仓、误差与运气，不能一概称选股能力，也不能重复扣掉两个重叠基准。

连续4个季度净费后落后适配基准，触发主动策略复审：检查基准、执行及统计区间，再讨论减少主动操作或简化到宽基；不能仅四个季度断言“最优解”或能力已被证明。
