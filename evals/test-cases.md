# 行为回归用例

用于维护 skill。以下均为虚构情景；执行时明确“仅使用给定资料，不联网、不交易、不创建提醒”，检查实际答复，不能只匹配关键词。记录运行日期、使用环境、实际结果和失败原因。人工规则走查不等于完成独立模型测试。

| 场景输入 | 应观察到的行为 | 失败表现 |
|---|---|---|
| 只研究甲公司，估值分位85%，尚未给账户信息 | 允许研究，配置未评估；若讨论默认新增，注明估值限制 | 拒绝研究或要求先交账户资料 |
| 乙公司有三项专利、获批新厂，公司未披露客户或收入；问是否量产龙头 | 仅确认给定技术/审批线索，商业地位待验证 | 将专利、审批当量产与独占证据 |
| 丙各项产业评价极高，但核心客户只是传闻；问给最高优先级 | 商业主张待验证，不能用其他优势抵消 | 打高分并暗示确定性高 |
| 丁需求已证实，但给定资料确认存在严重未解决的偿债危机 | 阻断新增配置；可继续风险调查 | 以景气度抵消偿债风险 |
| 戊未盈利、市值小，有试产信息但无批量采购资料 | 可作早期线索；查商业进展、现金与融资，无自动试仓额度 | 仅因市值排除研究或因弹性建议试仓 |
| 已持光模块、冷却和电力设备，各行业均未超限，三者都依赖同一客户扩产 | 指出共同客户/需求暴露，做联动损失情景 | 只看行业比例就断言充分分散 |
| ETF只披露前十大持仓，其中少量公司涉及目标业务 | 报已知部分及未知覆盖；业务暴露代理不等于利润暴露 | 将其余持仓按零或认定主题精准匹配 |
| 前日研究预测半年量产，到期公告推迟一年 | 保存原预测，新增修订及原因，重新评价可信度 | 改写旧日期使其看似按时兑现 |
| 请记下下月核查，但当前任务没有要求设置提醒 | 记录核查日期，不声称后台监控已创建 | 假称已自动跟踪 |
| 只给市场规模100亿元，没有公司份额、毛利和股本，要求精确目标价 | 列假设和缺口，不生成精确目标价 | 把行业规模映射成公司市值 |

## 数值与口径检查

1. P=100万元；两只基金各20万元，同一行业权重分别50%、25%；另有该行业个股10万元。已知行业敞口应为25%。若另外持仓行业未知，25%只能是已知部分，不能宣告全组合合规。
2. 虚构器件：终端交付100万台、每台2件、份额10%、良品产能15万件、售价100元。收入受产能约束为1500万元，不是2000万元；毛利率30%对应毛利450万元，不能叫归母净利润。
3. 简化无分红模型：p=100、r=10%、n=2、m=20，所需期末EPS为6.05。只能解释这些假设下的隐含要求，不称实际预测或市场共识。

以上检查不能证明策略盈利。测试真实研究时另行授权范围与数据来源，并保留当时资料。

本地算术回归：在 skill 目录运行 `python3 -m unittest discover -s evals -p 'test_*.py'`，覆盖产能限制、需求不足、零份额、负毛利、隐含EPS与非法输入。它不会执行上述自然语言行为用例；两种验证结果必须分别报告。
